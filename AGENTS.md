# Working on DICESTRICT

Read README.md, docs/ARCHITECTURE.md, docs/VALIDATION.md and SECURITY.md first.

## Project boundaries

This is an original casual property strategy game, not an official Monopoly adaptation. Keep the board, names, rules text, graphics and sound original. The name DICESTRICT has not been commercially cleared.

The repository uses native browser ESM and Node 22+, with no JavaScript dependency installation required. Preserve the standalone local demo generated by scripts/build.mjs. Do not insert CommonJS require calls into src/.

## Change and validation

Keep the game reducer pure and deterministic. Bind remote actions to the authenticated peer identity and game/revision scope. Validate network payloads and saved states before use. Add regression tests for rule or protocol changes.

Run npm run check, npm test and npm run build. For UI/renderer/network changes, also run tests/browser.py with Playwright Chromium installed. Inspect its screenshots and report. Do not weaken the WebGL check to accept the fallback renderer, and do not report a two-context local test as a cross-network or real-device validation.

The offline bundle and static native ESM build must both remain usable. Avoid hidden external asset/font dependencies. Keep responsive and non-WebGL access to all properties.

## Security and deployment

Never credit persistent XP, a wallet or a leaderboard based only on a client/host result. Casual P2P checksums and deterministic dice are not anti-cheat. The authority, identity validation and idempotent reward ledger described in the architecture are not implemented services.

scripts/dev.mjs is a bounded, in-memory development signaling server, not production infrastructure. Do not add permanent TURN secrets, Supabase service-role keys or other credentials to client code. Do not deploy paid infrastructure, modify an existing database or publish on CrazyGames without explicit authorization.

Document tested behavior and remaining limits honestly. Avoid claiming millions of concurrent games without capacity measurements.
